Variables are like containers where we can store
information in our program. For example, we can
store a person's name, age, or grade in a variable.
Data types tell Python what kind of information is
stored, like a number, text, or true/false value.


============================================
KEY VOCABULARY
============================================
- variable: A name we give to a value so we can use it later in our code.
- data type: It tells us what kind of value we are working with.
- int: Used for whole numbers, like 10, 25, or 100.
- float: Used for numbers with decimal points, like 95.5 or 3.14.
- string: Used for text, like a name or a sentence.
- boolean: Used for values that are either True or False.
- value: The actual information stored inside a variable.
